# An-lisis-Exploratorio-de-Ventas-E-Commerce-y-Evaluaci-n-de-Canales-2025---2026-
Análisis de datos de ventas e-commerce (Ene 2025 - Ago 2026) para la planificación estratégica del H2 2026. Incluye limpieza, validación de duplicados y evaluación de la estacionalidad mensual y rendimiento de 4 canales de venta sobre un catálogo de 42 productos, optimizando la toma de decisiones.
